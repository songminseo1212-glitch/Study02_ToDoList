# Study02_ToDoList

브라우저에서 바로 실행되는 개인용 할 일 관리 앱 프로젝트입니다.
하루 10~20개 정도의 할 일을 관리하는 용도이며, 순수 JavaScript(HTML + CSS + JS)만 사용합니다.

## 주요 기능 (계획)

- 할 일 추가 / 수정 / 삭제
- 완료 체크
- 카테고리 분류 (업무 / 개인 / 공부)
- 진행률 보기
- `localStorage` 저장으로 새로고침해도 데이터 유지

## 문서

- [PRD.md](PRD.md): 제품 요구사항 문서 (기능, 데이터 모델, 화면 구성, 수용 기준, 마일스톤)

## 기술 스택

- HTML / CSS / 바닐라 JavaScript
- 외부 라이브러리, 빌드 도구, 서버 없음

## 진행 상태

- [x] PRD 작성
- [ ] M1: 기본 구조 + 추가/삭제 + 저장
- [ ] M2: 완료 체크 + 진행률
- [ ] M3: 카테고리 + 필터
- [ ] M4: 수정 + 일괄 삭제 + 스타일
- [ ] M5: 수용 기준 검증

## 실행 방법 (구현 후)

`index.html` 파일을 브라우저로 열면 바로 실행됩니다.
